PROTOTYPE · Throwaway logic, not production

Is a minimal Catalog Item enough for both the Artisan and AI to create Quote Lines?

This demo tests a deliberately small Business Catalog. A Catalog Item is a reusable seed, not a trade model or a live price link. Selecting one copies an editable Quote Line, then the Artisan sets the quantity and job-specific wording.

  • The Business Catalog exists only to help the Artisan or AI assistant select reusable content while drafting. A Quote also works without it.
  • A Catalog Item has only description, unit, pricing mode, and an optional default price. Its internal ID is not business-facing.
  • Stable wording belongs in the Catalog Item description. Technical detail belongs only on the copied Quote Line.
  • Manual selection and AI-assisted selection use the same operation: select an item, copy a Quote Line snapshot, then edit the Quote Line.
  • Saving an ad-hoc Quote Line to the catalog and updating a catalog default price are explicit Artisan actions. Nothing suggests, saves, or updates itself.
  • Later catalog edits never rewrite existing Quote Lines or published Quote Revisions.
  • Similar items remain separate until the Artisan decides otherwise. There is no automatic merge.
  • CHF, VAT, discounts, and levies stay with Quote calculation controls, not Catalog Items.

# Index terminologique français-anglais

Cet index sépare une transcription française vérifiée de la terminologie analytique anglaise. « Canonique proposé » est une recommandation pour le contenu éditable d'Easy Quote, pas une correction du document source. Les abréviations, jetons incomplets et graphies source restent littéraux dans les échantillons.
